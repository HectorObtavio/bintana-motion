# bintana-motion
Live code films for Bintana websites, served by GitHub Pages.
- `<name>.html?embed&...` : one film per file (exposure, capiz). Built with `film/build-embed.mjs` in the studio repo.
- `js/bintana-film-loader-<version>.js` : the film loader, applied in Webflow as a hosted script. Never edit a published version; add a new one.
